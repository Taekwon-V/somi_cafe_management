# 메인 페이지 디자인 고도화 SPEC (Draft)

## 1. 개요 및 목적
현재 흰 바탕의 단조로운 대시보드를 벗어나, 사용자가 창업 준비 작업을 할 때 "더 몰입감 있고 효율이 나는(작업할 맛이 나는)" 프리미엄 UI/UX로 메인 페이지를 개편합니다.

## 2. 주요 개선 포인트
- **배경 이미지(Background) 도입**: 밋밋한 단색 배경 대신 앱의 정체성을 살리는 배경 그래픽/이미지 적용
- **카드 UI 고도화**: 배경과 어우러지도록 카드의 투명도(Opacity), 그림자(Shadow), 입체감 개선
- **가독성 확보**: 화려한 배경 위에서도 텍스트와 칸반 보드가 뚜렷하게 보이도록 명도 대비(Contrast) 조절

---

## 3. 확정된 디자인 컨셉: 옵션 B (깔끔한 '미니멀 워크스페이스' 🌿)

- **배경**: 식물과 커피 잔이 있는 모던 일러스트 배경 (`/bg-workspace.jpg` 활용)
- **카드 스타일**: 배경 위에 새하얗고 깔끔하게 떠 있는 불투명 카드 (투명도 없음, 뚜렷한 가독성)
- **그림자(Shadow)**: 부드럽고 넓은 드롭 섀도우를 통해 배경과 카드를 명확히 분리
- **포인트 컬러**: 데이터 시각화(아이콘, 텍스트 포인트)에 생동감 있는 컬러 사용

---

## 4. 구현 세부사항 (Coding 에이전트 작업 지시서)
- **배경 처리**: `Dashboard.tsx`의 최상단 Box에 `background-image: url('/bg-workspace.jpg')` 적용, `background-size: cover`, `background-position: center`, `background-attachment: fixed` 설정.
- **오버레이**: 배경이 텍스트 가독성을 해치지 않도록 반투명한 흰색 오버레이(`rgba(255,255,255,0.4)`)를 추가로 덮을 것.
- **카드 UI 변경**: 기존 그라데이션 카드들을 순백색(`bgcolor: 'white'`)으로 변경하고, 아이콘과 숫자에만 원색 포인트(빨강, 노랑, 초록)를 줘서 깔끔하게 구성할 것.
