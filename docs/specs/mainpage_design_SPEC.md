# 메인 페이지 디자인 고도화 SPEC (Draft)

## 1. 개요 및 목적
현재 흰 바탕의 단조로운 대시보드를 벗어나, 사용자가 창업 준비 작업을 할 때 "더 몰입감 있고 효율이 나는(작업할 맛이 나는)" 프리미엄 UI/UX로 메인 페이지를 개편합니다.

## 2. 주요 개선 포인트
- **배경 이미지(Background) 도입**: 밋밋한 단색 배경 대신 앱의 정체성을 살리는 배경 그래픽/이미지 적용
- **카드 UI 고도화**: 배경과 어우러지도록 카드의 투명도(Opacity), 그림자(Shadow), 입체감 개선
- **가독성 확보**: 화려한 배경 위에서도 텍스트와 칸반 보드가 뚜렷하게 보이도록 명도 대비(Contrast) 조절

---

## 3. 확정된 디자인 컨셉: 옵션 B (깔끔한 '미니멀 워크스페이스' 🌿)

- **배경**: 화려한 일러스트를 제외하고, 화면 가장자리에 미니멀한 라인아트 요소가 들어간 크림빛 밝은 톤(`bg-minimal.jpg`) 배경 적용.
- **레이아웃(Floating Island)**: 브라우저 화면 전체를 덮지 않고, 앱 컨테이너(최대 너비 1440px)를 화면 중앙에 배치. 
  - 좌측 사이드바와 우측 메인 대시보드 박스를 시각적으로 완전히 분리(`gap: 3`)하여, 서로 독립된 둥근 섬(Island)처럼 떠 있는 느낌 연출.
- **사이드바**: 미드나잇 블루(Midnight Blue, `#0f172a`) 테마를 적용하여 메인 흰색 화면과 강렬하고 프로페셔널한 대비를 줌.
- **메인 화면 (Main Container)**: 순백색에 가까운 밝은 배경(`#f8f9fa`)에 부드럽고 넓은 드롭 섀도우(`box-shadow`)와 아주 얇은 실선 테두리(`border: 1px solid rgba(0,0,0,0.08)`)를 주어, 배경 그래픽과 경계를 명확히 분리하고 세련된 입체감을 극대화함.
- **상단 타이틀 바 (AppBar)**: 메인 화면 상단에 위치한 타이틀 바는 좌측 메뉴의 '활성화 상태'와 통일감을 주도록 짙은 네이비 배경(`#1e293b`)과 흰색 텍스트, 스카이블루(`#38bdf8`) 아이콘을 배치함.
- **포인트 컬러**: 데이터 시각화(아이콘, 텍스트 포인트, 칸반 뱃지)에 생동감 있는 컬러 사용.
- **부가 기능(BGM 플레이어)**: 사용자의 작업 효율(몰입감) 향상을 위해 우측 하단에 플로팅되는 BGM 플레이어 탑재. 로컬 MP3(차분한 재즈 & 경쾌한 업비트) 2종을 재생 및 스킵 가능.

## 4. 구현 세부사항 (Coding 에이전트 작업 지시서)
- **레이아웃 처리 (`Layout.tsx`)**: 
  - 최상단 래퍼에는 `minHeight: 100vh`와 꽉 찬 배경 이미지, 주변 패딩(`p: 4`) 설정.
  - 내부 컨테이너는 `maxWidth: 1440` 및 `display: flex`, `gap: 3`을 통해 Drawer와 Main 영역을 물리적으로 분리.
- **사이드바(Layout)**: Drawer 배경색을 `#0f172a`로 설정. 글씨와 아이콘은 `#f8fafc` 및 `#38bdf8`로 포인트. 활성화 메뉴는 `#1e293b`로 진하게 하이라이트.
- **메인 영역 (Main Box)**: 독립된 둥근 모서리(`borderRadius: 4`), 그림자, 얇은 테두리 적용. 스크롤이 모서리를 침범하지 않도록 `overflow: auto` 설정.
- **상단 타이틀 바 (AppBar)**: `bgcolor: '#1e293b'` 적용 및 좌우 상단 모서리에 `borderTopRadius: 16` 처리하여 메인 영역 굴곡과 일치시킴.
- **BGM 플레이어**: `BgmPlayer.tsx` 생성. `<audio>` 태그와 `useRef`를 사용하여 브라우저 정책(차단)을 우회하고 로컬 파일을 재생함.
