# Dashboard (대시보드) 상세 스펙

## 1. 개요
대시보드는 사용자가 서비스 접속 시 가장 먼저 마주하는 메인 화면 콘텐츠로, 카페 창업 프로젝트의 최근 업데이트 내역과 향후 그려나갈 카페의 대표 이미지를 한눈에 파악할 수 있도록 돕습니다.

## 2. 주요 기능 및 UI 구성

### 2.1. 액자형 비전 보드 (Vision Board)
- **목적**: 창업할 카페의 전체적인 분위기나 현재까지의 구상을 한 장의 대표 이미지로 시각화합니다.
- **UI 구성**:
  - 화면 상단 또는 중앙 영역에 세련된 액자 형태의 UI 레이아웃을 배치합니다.
  - 개발 초기 단계에서는 '모던 코지(Modern Cozy)' 컨셉의 기본 이미지를 노출합니다.
  - **버전 표시**: 이미지의 우측 하단에 날짜 기반의 버전(예: `v2026.08.07`)을 작지만 시인성 있게 표시합니다.
- **인터랙션 (갤러리 팝업)**:
  - 액자 이미지를 클릭하면 모달 팝업 형태의 '히스토리 갤러리'가 오픈됩니다.
  - 갤러리에서는 과거에 업데이트되었던 비전 보드 이미지들의 내역을 열람할 수 있습니다.

### 2.2. 최근 업데이트 요약 (Recent Updates)
- **목적**: 다른 팀원들이 각 메뉴 카테고리에서 어떤 새로운 내용을 추가하거나 수정했는지 한눈에 파악합니다.
- **대상 카테고리**: 인테리어, 메뉴 및 레시피, 브랜딩 등 주요 협업 메뉴 (단, '멤버 관리' 등 관리자 메뉴는 제외)
- **UI 구성**:
  - 시각적으로 깔끔한 리스트(또는 카드, 타임라인) 형태로 최근 변경 내역을 나열합니다.
  - 각 항목에는 변경된 카테고리 이름, 변경 요약, 업데이트 시간 등이 포함됩니다.

## 3. 제외 사항 (Out of Scope)
- **Task (할 일) 관리**: 대시보드의 복잡도를 줄이고 비전 보드와 업데이트 내역에 집중하기 위해 Task 관리 기능은 대시보드에서 완전히 제외합니다. (필요 시 추후 독립된 별도 메뉴로 기획)

## 4. 기타 개발 참고사항
- 초기 개발 시 비전 보드 이미지는 직접 생성한 정적 이미지를 활용하여 퍼블리싱합니다.
- 갤러리와 최근 업데이트 리스트의 데이터는 Mock Data(더미 데이터)를 활용해 레이아웃과 디자인을 먼저 완성합니다.
