# 상권 및 부동산 후보지 관리 기능 명세서 (SPEC)

## 1. 개요
* **기능명**: 상권 부동산 분석 보드 (Real Estate & Location Board)
* **목적**: 창업 동업자들이 카페 입지(부동산 매물) 후보를 스크랩하고, 보증금/임대료 등의 조건을 수집/비교하며 실시간으로 의견을 나눌 수 있는 전용 게시판 기능.

## 2. 주요 기능 및 UI/UX

### 2.1. 후보지 매물 리스트 뷰 (Card View)
* 사용자가 오프라인 임장이나 인터넷에서 찾은 매물 후보를 등록하고 카드로 조회.
* **카드 표시 정보**:
  - **매물 별칭** (예: "판교 백현동 35평 테라스 상가")
  - **금액 조건**: 보증금 / 월세 / 권리금 (명확하고 비교하기 쉽게 강조)
  - **스펙**: 면적 (평수 / ㎡), 주차 가능 대수
  - **한줄 요약 태그**: 긍정적 특징(예: `#넓은테라스`, `#코너자리`) 및 단점 태그

### 2.2. 매물 후보 상세 보기 (Detail View)
* **매물 갤러리**: 해당 상가 외부 전경, 내부 상태, 주변 상권 사진 등록.
* **위치 정보 및 지도 연동**: 간략한 주소 정보 제공 및 `OpenStreetMap(react-leaflet)` 기반의 инте랙티브 '지도 뷰' 토글 기능을 통해 등록된 모든 후보지의 지리적 분포를 핀 마커로 시각화.
* **상권 분석 메모**: 주변 주택단지 세대수, 주 연령층, 유동 인구 특징 등 정성적 분석 내용 기재 공간.
* **필수 체크리스트 (30~40평 기준)**: 
  - [ ] 자체 주차 공간 유무 (3대 이상 권장)
  - [ ] 전기 승압 가능 여부 (20kW~30kW 급)
  - [ ] 화장실 위치 (내부/외부, 남녀 분리 여부)
  - [ ] 수도 및 배수 시설 위치
* **실시간 댓글/평가**: 팀원들과 해당 후보지에 대해 "여기 월세가 너무 비싼데?", "테라스가 맘에 들어" 등 자유롭게 토론하고 투표(찬/반, 찜하기)하는 기능.

### 2.3. 매물 수평 비교표 (Comparison Table)
* 등록된 2개 이상의 매물을 선택하여 표(Table) 형태로 변환.
* 보증금, 월세, 권리금, 평수, 관리비 등을 한눈에 수평 비교할 수 있어 최종 의사결정을 돕는 기능.

## 3. 데이터 구조 (Schema Draft)
* `id`: 고유 식별자 (string)
* `title`: 매물 닉네임/별칭 (string)
* `location`: 주소 정보 (string)
* `size_pyeong`: 면적 평수 (number)
* `deposit`: 보증금 (number)
* `rent`: 월 임대료 (number)
* `premium`: 권리금 (number)
* `parking_capacity`: 주차 대수 (number)
* `images`: 사진 URL 배열 (string array)
* `analysis_notes`: 상세 분석 내용 (string)
* `status`: 현재 상태 (enum: '관심', '임장 예정', '임장 완료', '계약 검토', '패스')

## 4. 제약 사항 및 개발 규칙
* 중개 플랫폼(네이버 부동산 등) 정보의 자동 크롤링은 당장 구현하지 않으며, 사용자가 직접 수기로 등록하는 방식을 사용하여 빠르게 MVP를 구성한다.
* 민감한 금액 정보와 계약 관련 내용이 포함되므로, 팀원으로 초대된 관리자만 열람할 수 있도록 보안 처리 필수.
* `docs/real_estate_analysis.md` 에서 분석된 입지 조건(30~40평 권장 기준)을 UI 상의 툴팁이나 가이드로 제공하면 유용함.
