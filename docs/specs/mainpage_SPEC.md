# 메인 페이지 (Main Page) 스펙 정의서

## 1. 개요
카페 창업을 준비하는 동업자들이 로그인 후 가장 먼저 보게 되는 통합 대시보드 화면입니다. 전체적인 창업 준비 현황을 한눈에 파악하고, 각자 맡은 세부 실무(할 일)를 직관적으로 관리하는 것이 목적입니다.

## 2. 화면 구성 (레이아웃)
사용자가 직접 선택한 **"대시보드형(요약 카드) + 칸반 보드(포스트잇 작업 관리)"** 혼합 스타일을 적용합니다.

### 2.1. 상단: 전체 요약 대시보드 (카드형)
- 카테고리별(인테리어, 메뉴, 브랜딩 등) 진행 상황이나 주요 통계를 크고 깔끔한 카드 형태로 배치합니다.
- **비전 보드 히스토리 기능**: 최신 대표 이미지를 메인에 노출하고, 클릭 시 팝업 갤러리에서 좌우 화살표를 통해 과거에 구상했던 이전 컨셉 사진(이력)들을 넘겨볼 수 있게 지원합니다.

### 2.2. 하단: 실무 할 일 관리 (칸반 보드형)
- 구체적인 실행에 옮겨야 할 작업들을 포스트잇처럼 관리하는 영역입니다.
- **상태 구분**: `할 일(To-Do)`, `진행 중(In Progress)`, `완료(Done)` 3가지 기둥(컬럼)으로 나눕니다.
- **기능**: 새로운 할 일을 쉽게 추가하고, 작업이 진행됨에 따라 상태를 변경할 수 있어야 합니다.

## 3. 데이터 연동 로직
- 누군가 할 일을 추가하거나 완료 처리하면, 다른 동업자가 접속했을 때도 똑같이 적용된 상태(동기화)로 보여야 합니다. (DB 저장 필수)
