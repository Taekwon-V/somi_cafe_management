# 브랜딩 및 마케팅 메뉴 스펙 문서 (Branding Menu SPEC) - V2 (갤러리형)

## 1. 개요
본 문서는 카페 창업 협업 툴의 '브랜딩 및 마케팅' 카테고리 화면에 대한 기능 스펙을 정의합니다. 기존의 마크다운 기반 텍스트 편집기 대신, 시각적인 영감을 주고 직관적인 관리가 가능한 **카드 그리드(Card Grid) 갤러리형 UI**를 채택합니다.

## 2. 화면 레이아웃 (UI Structure)

### 2.1. 메인 대시보드 (갤러리 뷰)
* **카드 그리드 배치:** 기획 주제(예: 핵심 정체성, 타겟 고객, 로고 시안, 인테리어 무드보드)가 각각 하나의 '카드'로 표현되며, 그리드(격자) 형태로 나열됩니다.
* **카드 디자인:** 
  * 상단: 주제에 맞는 시각적 썸네일 이미지 (배경 이미지).
  * 중앙/하단: 주제의 제목(Title)과 간단한 진행 상태(예: 초안 작성 중, 논의 완료 등).
  * 마우스를 올리면(Hover) 부드럽게 확대되거나 카드가 약간 떠오르는 동적 모션(Elevation)을 적용하여 모던함을 극대화합니다.
* **새로운 주제 추가:** 그리드 마지막에 [+] 형태의 빈 카드를 두어 언제든 새 주제를 추가할 수 있게 합니다.

### 2.2. 상세 보기 패널 (Slide-over Drawer 또는 Modal)
* 카드를 클릭하면 통짜 마크다운 에디터가 열리는 것이 아니라, 화면 우측에서 부드럽게 슬라이드 되어 나오는 패널(Drawer) 형태를 띕니다.
* **명확한 입력 폼(Form) 제공:** 
  * 예를 들어 '핵심 정체성' 카드를 열면 텅 빈 백지가 아니라, [미션], [비전], [브랜드 페르소나]를 각각 텍스트 박스로 명확히 나누어 제공합니다.
  * 복잡한 에디터 툴바를 숨기고, 직관적이고 깔끔한 텍스트 필드를 배치하여 누구나 쉽게 아이디어를 채워 넣을 수 있게 합니다.
* **이미지 갤러리 지원:** '무드보드'나 '로고 시안' 카드인 경우, 텍스트 폼보다는 이미지를 여러 장 업로드하고 크게 볼 수 있는 갤러리 레이아웃으로 변형됩니다.

## 3. 데이터베이스 모델링 (Firestore)
기존 `branding_docs` 컬렉션의 구조를 갤러리형에 맞게 최적화합니다.
* 필드 구조: 
  * `id`: 카드 고유 ID
  * `title`: 카드 제목 (예: "핵심 정체성")
  * `thumbnailUrl`: 카드 커버 이미지 URL
  * `fields`: 입력 폼 데이터 (JSON/Map 형태. 예: `{ mission: "...", vision: "..." }`)
  * `images`: 갤러리형 카드인 경우 첨부된 이미지 URL 배열
  * `updatedAt`: 최종 수정 시간

## 4. 디자인 시스템 가이드 (Aesthetics)
* **색상:** 어두운 배경(Dark mode)을 베이스로 하여 카드 안의 이미지나 텍스트가 돋보이도록 하는 '프리미엄 갤러리' 느낌을 지향하거나, 맑은 여백을 활용한 핀터레스트(Pinterest) 스타일의 화이트톤 디자인.
* **모서리 둥글기:** 카드의 모서리는 둥글게(border-radius: 12px~16px) 처리하여 부드럽고 세련된 느낌을 줍니다.
* **그림자와 깊이감(Depth):** 플랫한 디자인보다는 은은한 그림자(box-shadow)를 통해 UI의 깊이감을 더합니다.
