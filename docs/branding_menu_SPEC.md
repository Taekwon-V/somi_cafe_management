# 브랜딩 및 마케팅 메뉴 스펙 문서 (Branding Menu SPEC)

## 1. 개요
본 문서는 카페 창업 협업 툴의 '브랜딩 및 마케팅' 카테고리 화면에 대한 기능 스펙을 정의합니다. 방대한 기획 내용을 체계적으로 관리하기 위해 **문서 특화형 (위키/노션 스타일)** UI를 채택합니다.

## 2. 화면 레이아웃 (UI Structure)

### 2.1. 2단 레이아웃 구조
* **좌측 사이드바 (트리 구조 네비게이션):** 전체 문서의 목차를 계층형(Tree)으로 보여줍니다.
* **우측 메인 에디터 (Rich Text Editor):** 선택된 문서의 내용을 읽거나 수정할 수 있는 넓은 작업 공간입니다.

## 3. 상세 기능 (Features)

### 3.1. 좌측 사이드바 (문서 트리 관리)
* **폴더 및 문서 생성:** 새로운 카테고리(상위 폴더)와 세부 문서(하위 페이지)를 무한 뎁스(Depth)로 생성할 수 있습니다.
  * *예시 구조:*
    * 📂 1. 핵심 정체성
      * 📄 미션과 비전
      * 📄 브랜드 페르소나
    * 📂 2. 시각적 정체성
      * 📄 로고 디자인 시안
      * 📄 무드보드
* **이름 변경 및 삭제:** 생성된 문서/폴더의 이름을 변경하거나 삭제할 수 있습니다.
* **접기/펴기 (Toggle):** 상위 폴더를 클릭하여 하위 문서를 접거나 펼쳐서 깔끔하게 볼 수 있습니다.

### 3.2. 우측 메인 에디터 (작업 공간)
* **위지윅(WYSIWYG) 지원:** 마크다운 문법이나 툴바를 이용해 글씨 굵기, 헤딩(h1, h2, h3), 글머리 기호 등을 직관적으로 작성할 수 있습니다.
* **이미지 업로드 (Drag & Drop):** 시안 이미지, 무드보드 사진 등을 에디터 영역에 바로 끌어다 놓아 업로드하고 본문에 삽입할 수 있습니다.
* **자동 저장 (Auto-save):** 동업자들이 문서를 수정할 때마다 날아가지 않도록, 입력 후 일정 시간이 지나면 자동으로 데이터가 저장됩니다.
* **실시간 동기화 (향후 고려):** 다른 동업자가 같은 문서를 편집 중일 때 실시간으로 반영되는 기능 (MVP 버전에서는 자동 저장 기능까지만 우선 구현).

## 4. 디자인 시스템 가이드
* **테마:** 기존 UI와 어우러지는 모던하고 깔끔한 화이트/라이트 그레이 톤의 에디터. (또는 전체 시스템 다크모드 적용 시 고급스러운 다크 위키 테마 적용)
* **타이포그래피:** 가독성이 뛰어난 산세리프 폰트 (예: Pretendard, Inter) 사용. 헤딩(제목)과 본문의 크기 대비를 명확히 하여 문서의 구조를 한눈에 파악하게 함.
