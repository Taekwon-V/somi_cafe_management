# 브랜딩 및 마케팅 메뉴 스펙 문서 (Branding Menu SPEC) - V2 (갤러리형)

## 1. 개요
본 문서는 카페 창업 협업 툴의 '브랜딩 및 마케팅' 카테고리 화면에 대한 기능 스펙을 정의합니다. 기존의 마크다운 기반 텍스트 편집기 대신, 시각적인 영감을 주고 직관적인 관리가 가능한 **카드 그리드(Card Grid) 갤러리형 UI**를 채택합니다.

## 2. 화면 레이아웃 (UI Structure)

### 2.1. 기획안 탭 (Tabs) 및 메인 대시보드
* **다중 기획안 지원:** 여러 개의 브랜드 기획 방향성(A안, B안 등)을 독립적으로 관리할 수 있도록 화면 상단에 탭(Tabs) UI를 제공합니다.
* **컨셉 타이틀 & 1줄 요약 헤더:** 탭 내부 상단에는 기획안의 이름과 부제목, 그리고 4개의 기획 항목에 대한 '1줄 요약' 문장이 카드 형태로 나열되어 큰 그림을 한눈에 파악하게 합니다.

### 2.2. 오픈형 매거진 레이아웃 (새로운 뷰어 모드)
* 기존 팝업(Drawer) 기반의 수정 모드를 완전히 폐기하고, **읽기 전용(Read-only) 프레젠테이션 보드** 형태로 전환합니다.
* **세부 내용 전면 노출:** 2x2 그리드 카드의 크기를 충분히 확장하여, 각 카테고리의 썸네일 이미지 아래로 세부 항목(Mission, Vision, USP 등)의 텍스트가 모두 밖으로 꺼내어져 깔끔하게 나열됩니다.
* 마우스 클릭이나 뎁스 이동 없이, 화면을 스크롤하며 기획안의 모든 내용을 한눈에 감상하고 팀원들과 의견을 나눌 수 있는 **쇼케이스(Showcase) 형태**로 디자인합니다.

## 3. 데이터베이스 모델링 (Firestore)
기존 `branding_docs` 컬렉션의 구조를 갤러리형에 맞게 최적화합니다.
* 필드 구조: 
  * `id`: 카드 고유 ID
  * `title`: 카드 제목 (예: "핵심 정체성")
  * `thumbnailUrl`: 카드 커버 이미지 URL
  * `fields`: 입력 폼 데이터 (JSON/Map 형태. 예: `{ mission: "...", vision: "..." }`)
  * `images`: 갤러리형 카드인 경우 첨부된 이미지 URL 배열
  * `updatedAt`: 최종 수정 시간

## 4. 디자인 시스템 가이드 (Aesthetics)
* **색상:** 어두운 배경(Dark mode)을 베이스로 하여 카드 안의 이미지나 텍스트가 돋보이도록 하는 '프리미엄 갤러리' 느낌을 지향하거나, 맑은 여백을 활용한 핀터레스트(Pinterest) 스타일의 화이트톤 디자인.
* **모서리 둥글기:** 카드의 모서리는 둥글게(border-radius: 12px~16px) 처리하여 부드럽고 세련된 느낌을 줍니다.
* **그림자와 깊이감(Depth):** 플랫한 디자인보다는 은은한 그림자(box-shadow)를 통해 UI의 깊이감을 더합니다.
